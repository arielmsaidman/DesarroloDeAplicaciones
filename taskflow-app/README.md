TaskFlow

TaskFlow es una aplicación móvil desarrollada con React Native y Expo, orientada a la gestión y organización de tareas.

Tecnologías
React Native
Expo
JavaScript
Instalación

Clonar el repositorio y acceder a la carpeta del proyecto:

git clone URL_DEL_REPOSITORIO
cd taskflow-app

Instalar las dependencias:

npm install

Iniciar el proyecto:

npx expo start

Luego, el proyecto puede ejecutarse utilizando Expo Go o un emulador de Android.
